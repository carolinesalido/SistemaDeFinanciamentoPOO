# Sistema de Financiamento Bancário

Sistema desenvolvido em Java para gerenciamento de financiamentos imobiliários, aplicando os fundamentos de Programação Orientada a Objetos.

---

## Funcionalidades

- Cadastro de financiamentos de casa, apartamento e terreno
- Cálculo de valor total com juros e parcelas mensais
- Validação de regras de negócio com exception personalizada

---

## Conceitos de POO aplicados

- Herança — `Casa`, `Apartamento` e `Terreno` herdam de `Financiamento`
- Polimorfismo — cada subclasse sobrescreve comportamentos da superclasse
- Encapsulamento — atributos privados com getters e setters
- Interface — `InterfaceUsuario` define os métodos de interação
- Exception personalizada — `AumentoMaiorDoQueJurosException`

---

## Tecnologias

- Java
- IntelliJ IDEA

---

## Como executar

1. Clone o repositório:
```bash
git clone https://github.com/carolinesalido/SistemaDeFinanciamentoPOO.git
```
2. Abra no IntelliJ IDEA via `File → Open`
3. Execute a classe `Main.java`
